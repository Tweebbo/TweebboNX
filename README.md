# Tweebbo for Nintendo Switch

Play in the same hotel as [tweebbo.lol](https://tweebbo.lol). Build rooms, chat with friends, collect furniture and pets, and play games with people on the web and other consoles.

**[Download for Nintendo Switch](https://github.com/Tweebbo/TweebboNX/releases/latest)** · [Release notes](RELEASE.md)

## Install

You need a Nintendo Switch with homebrew enabled (Atmosphere and the Homebrew Menu).

1. Download `tweebbo.nro` from the latest release.
2. Copy it to `switch/Tweebbo/tweebbo.nro` on your SD card.
3. Hold R while starting a game from the HOME Menu, then choose Tweebbo in the Homebrew Menu.
4. Connect to the internet to enter the hotel, or choose Play offline on the start screen.

## Controls

| Control | Action |
| --- | --- |
| Left stick | Walk |
| A | Talk, use furniture or confirm |
| B | Open rooms, close or cancel |
| Y / X | Chat / wave |
| D-Pad | Walk, navigate lists or move furniture while placing |
| L / R | Zoom; turn pages in windows; rotate or change height while placing |
| ZL / ZR | Open Tools in the room; change catalogue section or Navigator page |
| + | Quit |

The room shows a button legend in the top-left corner. In Chat, L/R shows older/newer messages. Support is in the bottom toolbar and Tools.

## Progress and updates

Use your private character code to play with the same character on the web and other consoles.

Tweebbo offers Update now when a newer release is available. You can also check from Help → Search for updates. The updater verifies the download's SHA-256 before replacing `tweebbo.nro` and keeps the previous file as `tweebbo.nro.bak`. Close Tweebbo and reopen it from the Homebrew Menu after updating.
